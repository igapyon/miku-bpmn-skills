# PM0001-00001 — 対象範囲を決める

## プロンプト

利用者の依頼と指定された miku-daybook の記録から、今回再利用したい仕事の範囲を特定してください。

- 利用者の依頼 `{{request}}`
- 対象 activity の参照または本文 `{{activities}}`
- 関連 task の参照または本文（任意） `{{related_tasks}}`

1. `igapyon-miku-daybook` に従い、指定された記録を開いて本文を読んでください。貼り付けられた本文も入力にできます。抜粋だけを確認できた場合は、提供された範囲を示してください。
2. 対象の仕事を「何を受け取って始まり、何を返すまでか」で述べてください。日付だけで区切らず、同じ activity に別の目的、成果物、後日の作業が混在するときは、対象の箇所と範囲外の箇所を示してください。仕事が複数の activity に続く場合は、そのつながりを記録してください。
3. 関連 task が読める場合は、目的、完了条件、計画や進捗を、記録当時の文脈として要約してください。実際の作業を拾う根拠には activity を使います。関連 task がない場合も進めてください。
4. 記録を特定できない場合や、開始点・終了点の解釈で候補の内容が変わる場合は、その点を利用者に確認してください。範囲が明確な場合は根拠表の作成へ進めます。補足記録が読めない場合は、読めた範囲とその制約を添えます。

### 出力

- **対象範囲と記録一覧**
  - 仕事の目的、開始点、終了点。開始点や終了点が記録に見当たらなければ、その旨。
  - activity ごとの参照 ID（`A01` など）、会話内でたどれる参照、日付、対象の見出しまたは箇所、範囲外とした箇所と理由。抜粋の場合は、その範囲。
  - 参照した task の文脈、読み取れなかった記録、範囲に影響する確認事項。

Process 候補を束ねた親と子の BPMN 例は [P0002-00000](../../bpmn/P00002/P0002-00000.md) と、そのリンク先の5つの定義です。XML は非実行用の構造例で、BPMN 実行エンジンでの動作は確認していません。

v0.4.4 の実行では Ready for Review、マージ、ブランチ削除、Release 公開を順に案内し、それぞれの報告を受けました。その後の利用者の要望を反映し、現在の親 Process では Draft PR の作成後、操作への習熟度に応じて一つずつ案内するか、手順一式を示すかを選べます。完了報告の後に AI がマージと Release を照合し、この合図で pull するよう事前に依頼されていれば次の作業ブランチを作ります。v0.4.2 の作業から作った候補と、v0.4.4 の実行後に現在の定義へ反映した変更は、[候補と原記録の照合](PM0002-00004-review.md#v044-の実行を踏まえた見直し) からたどれます。

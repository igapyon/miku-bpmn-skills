# PM0002-00001 — 対象範囲を決める

2026-11-28 の miku-daybook activity「miku-bpmn の GitHub Release 手順を記録」（A01）から最初の候補を作りました。同日の activity「miku-bpmn の新しい操作を記録」（A02）のうち、v0.4.4 の実行実験とその見直しを、定義を再利用した結果として参照します。

[対応する P00001 のプロンプト](../P00001/PM0001-00001-scope.md)

## 対象範囲

対象は、既存の作業ブランチで変更中の文書を受け取った状態から、version 0.4.2 の変更を commit し、Draft PR を作成して人が merge・Release 公開し、マージを検証して次の work branch を作るまでです。作業開始時点で未 commit だった文書の作成・変更そのものは入力として扱います。関連 task は参照していません。

A01 は v0.4.2 の作業から候補を見つけるため、A02 は同じリポジトリで v0.4.4 を公開したときの結果から候補を見直すために使います。別のリポジトリや Release 方針への適用は今後の確認事項です。

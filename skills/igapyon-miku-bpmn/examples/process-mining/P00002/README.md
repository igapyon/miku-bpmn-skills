# P00002 — miku-bpmn の GitHub Release

Detailed Activity Mode で記録した、版数更新から GitHub Release 公開後の sync pull までを題材にしたプロセス発見の例です。[P00001 の5段階プロンプト](../P00001/README.md) に沿って、今回の activity から得た内容を各ファイルにまとめています。

| 段階 | 内容 |
| --- | --- |
| [1. 対象範囲](PM0002-00001-scope.md) | どの作業記録を対象にし、どの状態からどこまでを扱ったか |
| [2. 操作と根拠](PM0002-00002-evidence.md) | 原記録の見出しと、そこから確認した10件の出来事 |
| [3. Process 候補の発見](PM0002-00003-discover.md) | 再利用できる5件の候補と、それぞれの入出力・完了条件 |
| [4. 候補と原記録の照合](PM0002-00004-review.md) | タスクと根拠の対応、実例と追加案の確認 |
| [5. Process の定義化](PM0002-00005-save.md) | 候補に対応する子 Process と、それらを呼び出す親 Process |

BPMN の定義は、[親 Process](../../bpmn/P00002/P0002-00000.md) からもたどれます。

# P0002-00003 Draft PR を review して merge する

## 目的と入力

Draft PR の変更を人が review し、合意した変更だけを対象 base に merge します。入力は `{{draft_pr_url}}`、published head branch、base branch、PR head SHA、review authority です。

## 手順と判断

1. User Task `P0002-00003-task-01` で人が Draft PR の差分と base を確認し、Ready for Review にします。この User Task は人が ready と判断して Ready for Review にした場合にだけ完了します。変更要求または停止なら Process はここで待ち、merge へ進みません。AI は人の review を代行しません。
2. User Task `P0002-00003-task-02` で人が Merge pull request、続いて Confirm merge を操作します。画面の対象 PR と base が入力に合うことを確認します。マージされたことを画面で確認し、後続の Release で使うマージコミットを PR の結果から特定します。
3. User Task `P0002-00003-task-03` で人がリポジトリの方針に従ってマージ済みの公開ブランチを削除するか保持します。

親 Process では、これらの操作と P0002-00004 の Release 公開を、[利用者が希望する方法](P0002-00000.md#github-操作の案内) で案内します。記録例では、利用者が PR #8 の Ready for Review、Merge pull request、Confirm merge、Delete branch を操作したと報告しました。

## 出力と完了条件

対象 PR の URL と番号、公開ブランチ、head SHA、base ブランチと、人が確認したマージ結果を P0002-00004 に渡します。人がマージを確認し、公開ブランチの扱いを決めたら完了です。AI による照合は Release の完了報告を受けて行います。

# P0001-00001 構想と名前を決める

## 目的と入力

利用者のアイデアと利用例から、何を扱う `{{product_type}}` かを決めます。今回の題材では、製品種別は Agent Skill です。

## BPMN XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<bpmn:definitions xmlns:bpmn="http://www.omg.org/spec/BPMN/20100524/MODEL"
                  id="Definitions_P0001-00001"
                  targetNamespace="https://example.org/miku-bpmn/P00001/P0001-00001">
  <bpmn:process id="P0001-00001" name="構想と名前を決める" isExecutable="false">
    <bpmn:startEvent id="P0001-00001-start" name="開始"/>
    <bpmn:task id="P0001-00001-task-01" name="利用者、課題、利用例を整理する"/>
    <bpmn:task id="P0001-00001-task-02" name="関連概念と標準を調べる"/>
    <bpmn:task id="P0001-00001-task-03" name="企画案と名前候補をまとめる"/>
    <bpmn:userTask id="P0001-00001-confirm" name="企画案と名前を確認する"/>
    <bpmn:endEvent id="P0001-00001-end" name="確認済み"/>
    <bpmn:sequenceFlow id="P0001-00001-flow-01" sourceRef="P0001-00001-start" targetRef="P0001-00001-task-01"/>
    <bpmn:sequenceFlow id="P0001-00001-flow-02" sourceRef="P0001-00001-task-01" targetRef="P0001-00001-task-02"/>
    <bpmn:sequenceFlow id="P0001-00001-flow-03" sourceRef="P0001-00001-task-02" targetRef="P0001-00001-task-03"/>
    <bpmn:sequenceFlow id="P0001-00001-flow-04" sourceRef="P0001-00001-task-03" targetRef="P0001-00001-confirm"/>
    <bpmn:sequenceFlow id="P0001-00001-flow-05" sourceRef="P0001-00001-confirm" targetRef="P0001-00001-end"/>
  </bpmn:process>
</bpmn:definitions>
```

## 手順と判断

1. `P0001-00001-task-01` で、想定する利用者、解決したいこと、利用例を整理します。
2. `P0001-00001-task-02` で、適用できる既存の概念や標準を調べ、人が理解できる手順になるかを利用例に照らします。
3. `P0001-00001-task-03` で、対象、採用する概念や標準、初版の範囲を企画案にまとめます。`{{product_name}}` の候補と、それぞれの名前から利用者に伝わることを示します。
4. User Task `P0001-00001-confirm` で利用者に企画案と名前を確認します。回答を待ち、確認した内容を出力に反映します。

## 出力と完了条件

利用者が確認した企画、製品名・リポジトリ名・Skill 名、未決事項の一覧を渡せる状態になったら完了です。

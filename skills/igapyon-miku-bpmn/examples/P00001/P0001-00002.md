# P0001-00002 Agent Skill の初稿を作る

## 目的と入力

確認済みの企画、`{{product_name}}`・`{{repository_name}}`・`{{skill_name}}`、未決事項の一覧を受け取り、利用者が指定した `{{work_repository}}` で `{{product_type}}` の初稿を作ります。今回の題材では、製品種別は Agent Skill です。

## BPMN XML

```xml
<?xml version="1.0" encoding="UTF-8"?>
<bpmn:definitions xmlns:bpmn="http://www.omg.org/spec/BPMN/20100524/MODEL"
                  id="Definitions_P0001-00002"
                  targetNamespace="https://example.org/miku-bpmn/P00001/P0001-00002">
  <bpmn:process id="P0001-00002" name="Agent Skill の初稿を作る" isExecutable="false">
    <bpmn:startEvent id="P0001-00002-start" name="開始"/>
    <bpmn:task id="P0001-00002-task-01" name="作業先を確認する"/>
    <bpmn:task id="P0001-00002-task-02" name="規約に沿った初稿を作成する"/>
    <bpmn:task id="P0001-00002-task-03" name="成果物間の整合を確認する"/>
    <bpmn:endEvent id="P0001-00002-end" name="初稿完成"/>
    <bpmn:sequenceFlow id="P0001-00002-flow-01" sourceRef="P0001-00002-start" targetRef="P0001-00002-task-01"/>

    <bpmn:sequenceFlow id="P0001-00002-flow-04" sourceRef="P0001-00002-task-03" targetRef="P0001-00002-end"/>
  </bpmn:process>
</bpmn:definitions>
```

## 手順と判断

1. `P0001-00002-task-01` で指定された作業先を確認します。作業先を特定できない場合は、利用者にリポジトリの場所を確認します。
2. `P0001-00002-task-02` で、適用する `{{skill_creation_guideline}}` に沿って初稿を作ります。今回の題材では、`README.md` に目的と導入方法、`skills/{{skill_name}}/SKILL.md` に起動条件と作業手順、`TODO.md` に仕様の未決事項と初版で確認する項目を記載しました。
3. `P0001-00002-task-03` で、成果物間の製品名・用途・対象範囲の整合を確認します。

## 出力と完了条件

3ファイルが揃い、記述の整合を確認したら、レビュー対象のファイルと `TODO.md` に記載した未決事項を渡します。

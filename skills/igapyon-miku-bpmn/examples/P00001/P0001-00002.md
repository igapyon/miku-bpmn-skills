# P0001-00002 Agent Skill の初稿を作る

## 目的と入力

確認済みの企画、製品名・リポジトリ名・Skill 名、未決事項の一覧を受け取り、利用者が指定したローカルリポジトリで Agent Skill の初稿を作ります。

## 手順と判断

1. 指定された作業先を確認します。作業先を特定できない場合は、利用者にリポジトリの場所を確認します。
2. miku-soft の Agent Skills 作成手順に沿って、`README.md` に目的と導入方法、`skills/<skill-name>/SKILL.md` に起動条件と作業手順を書きます。
3. `TODO.md` に、仕様が未決の箇所と初版で確認する項目を記載します。
4. 3ファイル間で名前・用途・対象範囲が一致するか確認します。

## 出力と完了条件

3ファイルが揃い、記述の整合を確認したら、レビュー対象のファイルと `TODO.md` に記載した未決事項を渡します。

# P0001-00003 初稿をレビューして修正する

## 目的と入力

確認済みの企画と `README.md`、`SKILL.md`、`TODO.md` の初稿を照合し、利用者が期待する作業を SKILL の指示で進められるか確認します。

## 手順と判断

1. 企画と初稿を読み、代表的な利用例を一つ選びます。
2. 利用例を SKILL の記述に沿ってたどり、手順の抜けや文書間の食い違いを探します。
3. 合意済みの範囲で修正し、新たな仕様判断が要る点は `TODO.md` に残します。
4. 指摘箇所を読み直し、修正内容と未決事項が分かるようにまとめます。

## 出力と完了条件

指摘、反映した修正、残る判断を確認できる状態になったら、レビュー済みの初稿と修正の要約を返します。

# P0001-00003 初稿をレビューして修正する

## 目的と入力

確認済みの企画と `{{deliverables}}` の初稿を照合し、利用者が期待する作業を `{{skill_name}}` の指示で進められるか確認します。今回の題材では、成果物は `README.md`、`skills/igapyon-miku-bpmn/SKILL.md`、`TODO.md` です。

```xml
<?xml version="1.0" encoding="UTF-8"?>

  <bpmn:process id="P0001-00003" name="初稿をレビューして修正する" isExecutable="false">
    <bpmn:startEvent id="P0001-00003-start" name="開始"/>

    <bpmn:task id="P0001-00003-task-02" name="利用例をたどって不足を探す"/>
    <bpmn:task id="P0001-00003-task-03" name="合意済みの修正を反映する"/>
    <bpmn:task id="P0001-00003-task-04" name="修正と未決事項をまとめる"/>
    <bpmn:endEvent id="P0001-00003-end" name="レビュー完了"/>

  </bpmn:process>
</bpmn:definitions>
```

## 手順と判断

1. `P0001-00003-task-01` で企画と初稿を読み、代表的な利用例を一つ選びます。
2. `P0001-00003-task-02` で利用例を `{{skill_name}}` の記述に沿ってたどり、手順の抜けや成果物間の食い違いを探します。
3. `P0001-00003-task-03` で合意済みの範囲を修正し、新たな仕様判断が要る点は `{{open_decisions_document}}` に残します。今回の題材では `TODO.md` です。
4. `P0001-00003-task-04` で指摘箇所を読み直し、修正内容と未決事項が分かるようにまとめます。

## 出力と完了条件

指摘、反映した修正、残る判断を確認できる状態になったら、レビュー済みの初稿と修正の要約を返します。

# P0001-00001 構想と名前を決める

## 目的と入力

利用者のアイデアと利用例から、何を扱う Agent Skill かを決めます。

## 手順と判断

1. 想定する利用者、解決したいこと、利用例を整理します。
2. 適用できる既存の概念や標準を調べ、人が理解できる手順になるかを利用例に照らします。
3. 対象、採用する概念や標準、初版の範囲を企画案にまとめます。名前の候補と、それぞれの名前から利用者に伝わることを示します。
4. User Task `P0001-00001-confirm` で利用者に企画案と名前を確認します。回答を待ち、確認した内容を出力に反映します。

## 出力と完了条件

利用者が確認した企画、製品名・リポジトリ名・Skill 名、未決事項の一覧を渡せる状態になったら完了です。
